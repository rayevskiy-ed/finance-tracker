# Финансовый трекер

Регистрация/вход, веб-приложение (PWA), Telegram-бот, API-ключи. Стек: Python, FastAPI, SQLite.

## Запуск
    pip install -r requirements.txt
    export TELEGRAM_BOT_TOKEN=...   # необязательно, токен от @BotFather
    uvicorn app:app --host 0.0.0.0 --port 8000

Для iPhone нужен HTTPS (PWA и Shortcuts): разверните на VPS/Render/Fly.io за Caddy или nginx
с сертификатом. Safari → «Поделиться» → «На экран Домой».

## Telegram
Веб-приложение → Интеграции → Telegram → отправьте боту `/start КОД`.
Дальше: `350 кофе` (расход), `+50000 зарплата` (доход), `/balance`.

## API и iOS Shortcuts
Интеграции → API-ключ (виден один раз; новый заменяет старый).
Ярлык: «Получить содержимое URL» → POST `https://ВАШ-ДОМЕН/api/transactions`,
заголовок `Authorization: Bearer fk_...`, тело JSON: `{"amount": -350, "category": "Еда", "note": "Кофе"}`
(расход — минус, доход — плюс). Также: GET `/api/transactions`, GET `/api/summary`, DELETE `/api/transactions/{id}`.

## Безопасность
Пароли — scrypt с солью; токены хранятся как SHA-256; ограничение попыток входа.
Перед публичным запуском: HTTPS обязателен, делайте резервные копии `finance.db`.

## Дополнительно
- Навигация по месяцам, поиск, редактирование операций (тап по строке), быстрые категории.
- Бюджеты по категориям с индикатором; бот предупреждает при расходе от 80% лимита.
- Экспорт месяца в CSV, смена пароля (остальные устройства разлогиниваются), отвязка Telegram, удаление аккаунта.
- Бот: `/month` (расходы по категориям), `/undo` (удалить последнюю запись).
- API: `PUT /api/transactions/{id}`, `PUT /api/budgets`, `GET /api/export.csv?month=YYYY-MM`, фильтры `?month=&q=`.

## Merchant (магазин) и Apple Pay
У операции есть необязательное поле `merchant`. Если категория не указана, а магазин уже встречался,
категория подставится автоматически из последней операции с этим магазином. Старые базы обновляются сами.

Автоматический учёт оплат Apple Pay (iOS 17+):
1. Ярлыки → Автоматизация → Новая → **Транзакция** (Wallet), выберите карты, «Выполнять немедленно».
2. Действие «Получить содержимое URL»: POST `https://ВАШ-ДОМЕН/api/transactions`, заголовок `Authorization: Bearer fk_...`,
   тело JSON: `amount` (число, расход — отрицательный: умножьте сумму из «Ввода ярлыка» на −1) и `merchant` (текст, «Продавец» из «Ввода ярлыка»).
Набор полей транзакции зависит от версии iOS, проверьте на своём устройстве.

## Интерфейс и функции v4
Нижнее меню (Главная / Операции / Статистика / Ещё), кнопка «＋» с карточкой ввода (расход/доход, дата, быстрые категории),
кольцевая диаграмма расходов, график по дням, сравнение с прошлым месяцем, средний расход в день, операции по дням с итогами,
иконки категорий, выбор валюты, регулярные платежи/подписки (создаются автоматически в нужный день, API: `/api/recurring`).

## v5: дизайн и цели
Новый интерфейс: плавающее стеклянное меню, анимации, график на карточке баланса, 4 цветовые темы, светлая/тёмная/авто,
режим скрытия сумм (глаз на карточке баланса), тосты и формы вместо системных окон, фильтры операций, топ магазинов.
Цели накоплений: `GET/POST /api/goals`, `POST /api/goals/{id}/add` (отрицательная сумма — снять), `DELETE /api/goals/{id}`.

## v6: автоматизация
- **Секретная ссылка** (вкладка «Авто»): `GET/POST /api/hook/<токен>` только добавляет операции.
  `?text=350 кофе Starbucks` или JSON `{"amount":"1 250,50 ₽","merchant":"...","type":"expense","id":"..."}`.
  Без `type` положительная сумма считается расходом (доход — со знаком «+» или `type=income`).
- **Защита от дублей:** `id` / `external_id` (в том числе в `POST /api/transactions`).
- **Правила категорий** по ключевым словам (`/api/rules`), поверх авто-категории по истории магазина.
- **Импорт CSV** (`POST /api/import` или кнопка в приложении), экспорт и импорт совместимы.
- Суммы-строки вида «350,00 ₽» принимаются и в обычном API; `type` задаёт знак.
- Интерфейс: вкладка «Авто», прогноз месяца и «можно тратить в день», отмена удаления, дублирование операции, подсветка карточки баланса.

## v7
- **Счета и переводы:** `GET/POST /api/accounts`, `DELETE /api/accounts/{id}`, `POST /api/transfer {src,dst,amount}` (пустое имя — «Без счёта»).
  Переводы не попадают в доходы/расходы/бюджеты. В `POST /api/transactions` и в ссылке-хуке можно передать `account`.
- **Годовая статистика:** `GET /api/yearly?year=2026`, график по месяцам на вкладке «Статистика».
- **PIN-код** на вход (хранится хеш на устройстве, блокировка после минуты в фоне).
- **Вечерняя сводка в Telegram** (после 21:00, если были траты); `/digest on|off`.
- Ответ ссылки-хука содержит предупреждение о бюджете (поле `text`), его можно показать уведомлением в Ярлыках.

## v8
- **Инсайты** на главной (рост/падение категорий к прошлому месяцу, главная статья расходов, дни без трат), «Повторить в один тап» для частых трат, календарь-тепловая карта трат, жест свайпа для смены месяца, скелетоны загрузки.
- **Свои иконки и цвета категорий:** `GET/PUT /api/categories` (эмодзи «-» сбрасывает).
- **Бот:** `/help`, `/today`, `/budgets`. **Ссылка-хук** ограничена 60 запросами в минуту.
